# Категории контента — Оглавление

## 📚 Назначение

Эта папка содержит **описания категорий** для классификации контента. Каждая категория соответствует определённому направлению IT.

## 📁 Структура папки

| Файл | Категория | Описание |
|------|-----------|----------|
| `00_index.md` | — | Оглавление папки |
| `01_javascript.md` | `javascript` | JavaScript, TypeScript, Node.js |
| `02_php.md` | `php` | PHP и фреймворки |
| `03_css.md` | `css` | CSS, Tailwind, дизайн |
| `04_vpn_security.md` | `vpn_security` | VPN, vless, блокировки, безопасность |
| `05_hardware.md` | `hardware` | Гаджеты, железо, ноутбуки |
| `06_devops.md` | `devops` | Docker, CI/CD, облака |
| `07_patterns.md` | `patterns` | Паттерны, архитектура, SOLID |
| `08_databases.md` | `databases` | SQL, NoSQL, ORM |
| `09_ai_tools.md` | `ai_tools` | AI для разработчиков |

## 🏷️ Система тегов

### Основные теги (категории)

Используй **один основной тег** в каждом посте:

```
#javascript #php #css #vpn_security #hardware #devops #patterns #databases #ai_tools
```

### Дополнительные теги

Добавляй 2-4 дополнительных тега для детализации:

```
#javascript #typescript #nodejs #react
#php #laravel #symfony #composer
#vpn #xray #vless #security
```

## ✏️ Добавление новой категории

1. Создай файл `XX_category_name.md` в этой папке
2. Опиши категорию по шаблону
3. Добавь в это оглавление
4. Обнови `02_sources/08_keywords.md`
