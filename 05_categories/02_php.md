## 📰 Темы для публикаций

### Релизы и обновления

- Новые версии PHP (8.x, 9.x)
- Минорные и патч-релизы
- Security updates
- End of Life уведомления

### Фичи языка

- Property hooks, readonly classes
- Enums, match expression
- Attributes, fibers
- Типизация (union types, intersection types)
- JIT компиляция

### Фреймворки

- Laravel (новые версии, фичи)
- Symfony (LTS релизы, компоненты)
- Yii, CodeIgnerator, Slim
- Микрфреймворки (Mezzio, Spiral)

### Инструменты

- Composer (зависимости, плагины)
- PHPUnit, Pest (тестирование)
- PHPStan, Psalm, Rector (статический анализ)
- Xdebug, Blackfire (профилирование)

### Архитектура

- SOLID, паттерны в PHP
- DDD, CQRS, Event Sourcing
- Микросервисы vs монолит
- Hexagonal, Clean Architecture
