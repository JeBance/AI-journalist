# Сценарий: Еженедельный дайджест

## 📋 Цель

Подготовить итоговый пост с главными новостями недели (5-7 новостей).

**Время выполнения:** 15-20 минут  
**Частота:** Еженедельно (пятница/суббота)  
**Сложность:** Средняя

---

## 🔄 Шаги выполнения

### Шаг 1: Определение периода (1 минута)

Определи период дайджеста:

```
Дайджест за {начало недели} — {конец недели}
```

**Пример:**
- Дайджест за 18-24 марта 2026
- Дайджест за неделю 18-24 марта

### Шаг 2: Сбор новостей за неделю (5-7 минут)

#### 2.1. Проверка истории (1 минута)

1. Открой `06_history/01_published_posts.md`
2. Выпиши все посты за неделю
3. Это база для дайджеста

#### 2.2. Поиск пропущенных новостей (4-6 минут)

Проверь источники, которые могли быть пропущены:

**GitHub:**
- Проверь releases за неделю в критических репозиториях
- Выпиши важные релизы, которые не были опубликованы

**RSS:**
- Просмотри архивы RSS-лент за неделю
- Найди новости, которые пропустил

**Блоги:**
- Проверь технические блоги
- Найди статьи недели

### Шаг 3: Отбор новостей (3 минуты)

Выбери 5-7 главных новостей:

| Приоритет | Количество | Критерии |
|-----------|------------|----------|
| Критический | 1-2 | Security, breaking changes |
| Высокий | 2-3 | Major релизы, важные фичи |
| Средний | 2-3 | Интересные туториалы, мнения |

**Баланс категорий:**
- Старайся разнообразить категории
- Избегай 5 новостей об одном и том же

### Шаг 4: Написание дайджеста (5-7 минут)

Используй шаблон `03_templates/02_daily_digest.md`:

```
📰 *Дайджест за {период}*

{введение: 1-2 предложения об итогах недели}

---

1️⃣ *{Заголовок новости 1}*

{краткое описание: 2-3 предложения}

[Подробнее →]({ссылка})

---

2️⃣ *{Заголовок новости 2}*

...

(повторить для 5-7 новостей)

---

#дайджест #теги
```

**Требования к каждой новости:**
- Заголовок (чёткий, информативный)
- Описание (2-3 предложения)
- Ссылка на источник
- Категория (неявно через теги)

### Шаг 5: Добавление итогов недели (2 минуты)

Добавь секцию с итогами:

```
---

### 📊 Итоги недели

**Самая важная новость:** {новость}

**Самый обсуждаемый релиз:** {релиз}

**Ожидания на следующую неделю:** {ожидание}
```

### Шаг 6: Проверка качества (2 минуты)

Пройди чек-лист:

- [ ] 5-7 новостей
- [ ] Разные категории
- [ ] Краткие описания (2-3 предложения)
- [ ] Ссылки на источники
- [ ] Введение и итоги
- [ ] Теги релевантны
- [ ] Markdown корректен

### Шаг 7: Показ черновика (1 минута)

Покажи пост пользователю:

```
Готовый дайджест:

{текст поста}

---

✅ Чек-лист пройден
📊 Новостей: {N}
📝 Категорий: {N}
🏷️ Теги: {tags}

Опубликовать этот дайджест в Telegram?
```

### Шаг 8: Публикация и запись (2 минуты)

1. После подтверждения — опубликуй
2. Запиши в историю:
   - `06_history/01_published_posts.md`
   - `06_history/02_topics_covered.md` (если есть новые темы)
3. Обнови research cache

## 📊 Пример структуры дайджеста

```
📰 Дайджест за 18-24 марта 2026

Неделя релизов: PHP 8.4, Tailwind v4, Xray 1.8.24

---

1️⃣ PHP 8.4.0 released
(категория: php)

2️⃣ Tailwind CSS v4.0
(категория: css)

3️⃣ Xray-core 1.8.24
(категория: vpn_security)

4️⃣ TypeScript 5.8 beta
(категория: javascript)

5️⃣ PostgreSQL 17
(категория: databases)

---

📊 Итоги недели

Самая важная новость: PHP 8.4.0
Ожидания: PHP 8.5 RFC, Node.js 24
```

---

## 💡 Советы

- **Собирай новости в течение недели** — не оставляй на последний момент
- **Используй историю публикаций** — это готовая база
- **Добавляй контекст** — почему эта неделя важна
- **Публикуй в пятницу или субботу** — итог рабочей недели
