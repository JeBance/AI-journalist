# Шаблоны публикаций — Оглавление

## 📚 Назначение

Эта папка содержит шаблоны для разных типов публикаций. AI-агент должен выбирать соответствующий шаблон в зависимости от типа новости.

## 📁 Структура папки

| Файл | Описание | Когда использовать |
|------|----------|-------------------|
| `01_single_post.md` | Одиночная новость | Major/minor релиз, security patch |
| `02_daily_digest.md` | Ежедневный дайджест | 3-5 новостей за день |
| `03_breaking_news.md` | Срочная новость | Критическая уязвимость, breaking change |
| `04_tutorial.md` | Туториал / How-to | Пошаговая инструкция |
| `05_code_review.md` | Разбор кода/паттерна | Анализ кода, best practices |
| `06_comparison.md` | Сравнение технологий | Технология A vs Технология B |

## 📊 Типы постов и приоритеты

| Тип поста | Длина | Время на написание | Приоритет источников |
|-----------|-------|-------------------|---------------------|
| Single post | 150-300 слов | 2-3 мин | GitHub → RSS |
| Daily digest | 200-400 слов | 3-5 мин | Все источники |
| Breaking news | 100-200 слов | 1-2 мин | Telegram → GitHub |
| Tutorial | 400-800 слов | 5-10 мин | Блоги → Документация |
| Code review | 300-600 слов | 4-6 мин | GitHub → Блоги |
| Comparison | 300-500 слов | 4-6 мин | Блоги → Документация |

## ✏️ Использование шаблонов

1. Выбери подходящий шаблон по типу новости
2. Скопируй структуру
3. Заполни секции по инструкциям
4. Следуй правилам форматирования из `04_style/`
5. Добавь теги из `02_sources/08_keywords.md`

## 🔄 Модификация шаблонов

Можешь адаптировать шаблоны под свои нужды:
- Добавлять новые секции
- Изменять порядок блоков
- Создавать новые шаблоны

Главное — сохраняй читаемость и структуру.
