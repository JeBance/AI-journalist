# Шаблон: Срочная новость

## Инструкция

Используй этот шаблон для **критических новостей**, требующих немедленной публикации.

**Когда использовать:**
- Критическая уязвимость (CVE)
- Breaking changes в зависимостях
- Security incident
- Внезапные отключения сервисов

**Длина:** 100-200 слов

---

## Структура

```
🚨 **СРОЧНО**

{суть в одном предложении — что произошло}

---

### ⚡ Что случилось

{детали: 2-4 предложения}

### 🎯 Кто затронут

{аудитория: кто должен обратить внимание}

### 🔧 Что делать

{конкретные шаги: обновиться, проверить конфиги, и т.д.}

---

🔗 Источники

· {название источника}

#breaking #security #теги
```

---

## Пример заполнения

```
🚨 **СРОЧНО**

Критическая уязвимость в Xray-core CVE-2026-12345 позволяет обойти аутентификацию.

---

⚡ Что случилось

Обнаружена уязвимость нулевого дня в Xray-core версий 1.8.0–1.8.23. Злоумышленник может обойти аутентификацию при определённых конфигурациях Reality.

Уязвимость уже используется в дикой природе.

🎯 Кто затронут

Все пользователи Xray-core версий 1.8.0–1.8.23 с включённым Reality.

🔧 Что делать

1. Немедленно обновитесь до версии 1.8.24
2. Проверьте логи на предмет подозрительной активности
3. Пересоздайте ключи Reality

```bash
xray version  # должна быть 1.8.24
```

---

🔗 Источники

· GitHub Security Advisory
· Официальный релиз Xray-core

#breaking #security #xray #cve
```

---

## Советы по написанию

### Тон

- **Срочно, но без паники**
- Факты, а не эмоции
- Чёткие инструкции

### Структура

1. Первый абзац — самое важное (что случилось)
2. Детали — для тех, кто хочет понять
3. Инструкции — что делать читателю

### Скорость

- Публикуй в течение 15 минут после обнаружения
- Не жди подтверждения из нескольких источников
- Если информация неподтверждённая — укажи это

---

## Чек-лист перед использованием

- [ ] Заголовок содержит "СРОЧНО"
- [ ] Первый абзац объясняет суть
- [ ] Есть конкретные инструкции "Что делать"
- [ ] Указаны затронутые версии/конфигурации
- [ ] Есть ссылка на авторитетный источник
- [ ] Теги включают #breaking или #security
