## Пример заполнения

```
⚙️ **Настройка VLESS с Reality за 10 минут**

Пошаговая инструкция по настройке современного и безопасного протокола VLESS с Reality. Время: ~10 минут.

---

📋 Что понадобится

· Сервер с Ubuntu 22.04+
· Домен,指向щий на сервер
· Xray-core установлен

⏱️ Время: 10 минут

---

### Шаг 1: Генерация ключей

Сгенерируем приватный ключ для Reality:

```bash
xray x25519
```

Получим что-то вроде:

```
Private key: {private_key}
Public key: {public_key}
```

Сохраните оба ключа — они понадобятся в конфиге.

---

### Шаг 2: Создание конфига

Создайте файл `/usr/local/etc/xray/config.json`:

```json
{
  "inbounds": [{
    "port": 443,
    "protocol": "vless",
    "settings": {
      "clients": [{
        "id": "{uuid}",
        "flow": "xtls-rprx-vision"
      }],
      "decryption": "none"
    },
    "streamSettings": {
      "network": "tcp",
      "security": "reality",
      "realitySettings": {
        "show": false,
        "dest": "example.com:443",
        "xver": 0,
        "serverNames": ["example.com"],
        "privateKey": "{private_key}",
        "minClientVer": "",
        "maxClientVer": "",
        "maxTimeDiff": 0,
        "proxyProtocolVer": 0
      }
    }
  }]
}
```

---

### Шаг 3: Запуск Xray

```bash
systemctl restart xray
systemctl status xray
```

Убедитесь, что сервис активен.

---

### ✅ Проверка результата

Проверим, что порт слушается:

```bash
ss -tlnp | grep 443
```

Подключитесь клиентом с конфигом:

```json
{
  "outbounds": [{
    "protocol": "vless",
    "settings": {
      "vnext": [{
        "address": "your-server.com",
        "port": 443,
        "users": [{
          "id": "{uuid}",
          "flow": "xtls-rprx-vision",
          "encryption": "none"
        }]
      }]
    },
    "streamSettings": {
      "network": "tcp",
      "security": "reality",
      "realitySettings": {
        "serverName": "example.com",
        "publicKey": "{public_key}",
        "show": false
      }
    }
  }]
}
```

---

🔍 Что мы узнали

· Reality маскирует трафик под обычный HTTPS
· VLESS не требует шифрования на уровне протокола
· Настройка занимает менее 10 минут

---

## Советы по написанию

### Структура шагов

- Один шаг — одно действие
- Объясняй **почему**, а не только **что**
- Добавляй скриншоты для сложных шагов (если возможно)

### Код и команды

- Все команды в блоках кода
- Указывай ожидаемый вывод
- Предупреждай о возможных ошибках

### Проверка

- Всегда добавляй секцию проверки
- Дай команду для самотестирования
- Укажи, как исправить типичные ошибки
