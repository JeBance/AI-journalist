# Шаблон: Одиночный пост

## Инструкция

Используй этот шаблон для публикации **одной важной новости** или события.

**Когда использовать:**
- Major/minor релиз технологии
- Security patch / уязвимость
- Важный официальный анонс
- Breaking changes

**Длина:** 150-300 слов

## Пример заполнения

```
🔥 Xray-core 1.8.24: улучшенная обфускация VLESS и исправление утечки памяти

Вышел минорный, но важный релиз Xray-core. Разработчики закрыли уязвимость в логировании и улучшили маскировку трафика.

---

📌 Суть

Версия: 1.8.24
Дата: 2026-03-24

Основные изменения:

· Улучшена обфускация VLESS — трафик стал сложнее отличить от обычного HTTPS
· Исправлена утечка памяти при использовании Mux
· Обновлены зависимости (utls, quic-go)

💻 Технические детали

Конфиг для VLESS с Reality теперь поддерживает новые параметры:

```json
{
  "outbounds": [{
    "protocol": "vless",
    "settings": {
      "flow": "xtls-rprx-vision",
      "encryption": "none"
    }
  }]
}
```

🔍 Что это значит для вас?

Если вы держите публичные серверы — обновление рекомендуется. Утечка памяти могла приводить к падению сервиса на маломощных VPS. Новая обфускация повышает стабильность соединения при глубоком анализе трафика.

---

🔗 Источники

· Официальный релиз на GitHub
· Changelog

#vpn #xray #vless #security
```
