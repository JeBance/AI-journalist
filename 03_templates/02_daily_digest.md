# Шаблон: Ежедневный дайджест

## Инструкция

Используй этот шаблон для обзора **3-5 главных новостей за день**.

**Когда использовать:**
- Нет одной доминирующей новости
- Несколько важных событий за день
- Регулярная ежедневная публикация

**Длина:** 200-400 слов

---

1️⃣ **PHP 8.4.0 released: property hooks и без скобок для new**

Вышел финальный релиз PHP 8.4.0 с долгожданными фичами. Property hooks позволяют переопределять доступ к свойствам, а new без скобок делает код лаконичнее.

```php
// Property hooks
class User {
  public string $name {
    get => strtoupper($this->name);
    set => $this->name = trim($value);
  }
}

// New без скобок
$users[] = new User;
```

[Подробнее →](https://www.php.net/releases/8.4/)

· Совместимость с v3: 95%
· Время сборки: ~50ms для больших проектов
· Новый синтаксис конфигурации

## Советы по написанию

### Структура новостей

1. **Первая новость** — самая важная (критический приоритет)
2. **Вторая новость** — важная (высокий приоритет)
3. **Третья новость** — заметная (средний приоритет)
4. **4-5 новости** — опционально, если есть место

### Формат описания

- 2-3 предложения для каждой новости
- Избегай подробностей — только суть
- Добавляй ссылку "Подробнее" для каждой

### Баланс категорий

Старайся разнообразить категории:
- ✅ Хорошо: PHP + CSS + VPN
- ❌ Избегай: PHP + PHP + PHP
