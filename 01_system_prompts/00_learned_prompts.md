## 🆕 Новые правила

### 2026-03-25: Markdown V2 экранирование

**Проблема:** Telegram Markdown V2 требует экранирования специальных символов.

**Решение:** Всегда экранируй символы:
```
_ * [ ] ( ) ~ ` > # + - = | { } . !
```

**Примеры:**
- `PHP 8.4` → `PHP 8\.4`
- `#тег` → `\#тег`
- `AI-journalist` → `AI\-journalist`
- `> 3` → `\> 3`

## 🔄 Процесс обновления

### Когда добавлять новое правило

1. **Новая ошибка** — если AI ошибся и нашёл решение
2. **Новый нюанс** — если обнаружена важная деталь
3. **Изменение в API** — если изменился внешний сервис
4. **Новый источник** — если добавлен важный источник

1. Открой этот файл
2. Добавь правило в раздел "Новые правила"
3. Укажи дату и название
4. Опиши проблему и решение
5. Приведи примеры
