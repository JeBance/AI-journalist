# Чек-лист качества перед публикацией

## 📋 Обязательная проверка

### 1. Содержание

- [ ] **Фактологичность:** Все факты проверены по источникам
- [ ] **Актуальность:** Новость не старше 48 часов (для дайджеста — 7 дней)
- [ ] **Уникальность:** Тема не публиковалась в последние 30 дней
- [ ] **Релевантность:** Тема соответствует интересам аудитории
- [ ] **Полнота:** Все важные детали включены

### 2. Структура

- [ ] Есть заголовок (≤ 80 символов)
- [ ] Есть введение (1-2 предложения)
- [ ] Основная часть разделена на блоки
- [ ] Есть технические детали (если уместно)
- [ ] Есть практический контекст
- [ ] Указаны источники как кликабельные ссылки [название](URL)

### 3. Форматирование

- [ ] Telegram Markdown V2 корректен
- [ ] Все спецсимволы экранированы: `_ * [ ] ( ) ~ ` > # + - = | { } . !`
- [ ] Код в блоках ```code```
- [ ] Ссылки в формате `[текст](url)`
- [ ] Нет битых ссылок

### 4. Стиль

- [ ] Тон: экспертный, но дружелюбный
- [ ] Нет кликбейта без содержания
- [ ] Нет рекламных формулировок
- [ ] Технические термины использованы корректно
- [ ] Нет опечаток и грамматических ошибок

### 5. Теги

- [ ] Есть основной тег (категория)
- [ ] Есть 2-4 дополнительных тега
- [ ] Теги соответствуют содержанию
- [ ] Нет пробелов в тегах

### 6. Источники

- [ ] Минимум 1 источник
- [ ] Максимум 3 источника
- [ ] Ссылки рабочие
- [ ] Источники авторитетные
- [ ] **Оформлены как кликабельные ссылки [название](URL)**

---

## 🔍 Самопроверка AI

Перед показом черновика пользователю, ответь на вопросы:

1. **Правда ли это?** — Все факты проверены по источникам
2. **Полезно ли это?** — Читатель получит практическую ценность
3. **Ново ли это?** — Тема не повторяется из недавних публикаций
4. **Понятно ли это?** — Текст ясен целевой аудитории
5. **Корректно ли это?** — Нет нарушений законодательства

Если на все вопросы ответ **"Да"** — показывай черновик.

## ⚠️ Красные флаги

**Не публикуй, если:**

| Флаг | Описание |
|------|----------|
| 🚩 | Информация из непроверенного источника |
| 🚩 | Новость старше 7 дней без исторического контекста |
| 🚩 | Тема уже публиковалась менее 30 дней назад |
| 🚩 | Есть признаки рекламы без указания |
| 🚩 | Кликбейтный заголовок без содержания |
| 🚩 | Технические детали не соответствуют действительности |
| 🚩 | Есть призывы к незаконным действиям |

## 📊 Оценка качества поста

| Критерий | 5 (отлично) | 3 (нормально) | 1 (плохо) |
|----------|-------------|---------------|-----------|
| **Заголовок** | Интригующий + информативный | Просто информативный | Кликбейт или скучный |
| **Введение** | Ясно и кратко | Есть, но длинное | Отсутствует |
| **Основная часть** | Структурирована, полные детали | Есть структура | Хаотично |
| **Технические детали** | Точные версии, код | Только версии | Нет или ошибки |
| **Практический контекст** | Чёткие рекомендации | Общие слова | Отсутствует |
| **Источники** | 2-3 авторитетных | 1 источник | Нет или ненадёжные |
| **Форматирование** | Идеальное | Минорные ошибки | Много ошибок |

**Минимальный порог для публикации:** среднее ≥ 4

## ✅ Автоматическая публикация

**После прохождения чек-листа — публикуй автоматически:**

```python
from ai_journalist import TelegramClient, format_post

tg = TelegramClient()

post = format_post(
    title="Заголовок",
    content="Текст новости",
    hashtags=["теги"],
    emoji="🔥"
)

result = tg.send_message(post)

if result["success"]:
    print(f"✅ Опубликовано! Message ID: {result['message_id']}")
    # Запиши в историю
```

**Не публикуй, если:**
- ❌ Факты не проверены
- ❌ Тема повторяется (< 30 дней)
- ❌ Есть ошибки форматирования
- ❌ Текст на английском (должен быть на русском)

---

**Помни:** Один качественный пост лучше трёх посредственных.
