# AI-journalist — Полная документация

## 🚀 Что это?

**AI-journalist** — это файловая система знаний, которая превращает AI-агента (Claude, ChatGPT, Qwen, DeepSeek) в полноценного технического журналиста для Telegram-канала.

**Ключевая особенность:** Не требует программирования, сервера или базы данных. Вся логика хранится в Markdown-файлах.

---

## 📋 Возможности

### ✅ Базовые

- **Исследование источников** — GitHub, RSS, Telegram, блоги
- **Написание постов** — по шаблонам (single, digest, tutorial, etc.)
- **Публикация в Telegram** — через бота-посредника
- **Ведение истории** — предотвращение дублирования тем
- **Самообучение** — AI обновляет промты на основе опыта

### ✅ Продвинутые

- **Публикация на Telegra.ph** — длинные статьи с анонсом в канале
- **Глубокое исследование** — по запросу пользователя
- **Еженедельные дайджесты** — итоги недели
- **Срочные новости** — security patches, breaking changes

## 🎯 Сценарии использования

### Сценарий 1: Ежедневная публикация

**Цель:** Опубликовать свежую новость за 10-15 минут.

**Команда для AI:**
```
Изучи папку AI-journalist.

Выполни сценарий "daily_publication" из workflows.

Для публикации используй:
python3 /root/git/AI-journalist-bot/publisher.py "текст"
```

**Результат:** Пост в Telegram канале.

---

### Сценарий 2: Глубокое исследование с публикацией на Telegra.ph

**Цель:** Написать подробную статью и опубликовать с анонсом.

**Шаг 1: Подготовка**

Настройте Telegra.ph:
```bash
cd /root/git/AI-journalist-bot
# telegraph_config.json уже настроен
```

**Шаг 2: Команда для AI**

```
Изучи папку AI-journalist.

Выполни глубокое исследование по теме "PHP 8.4: полное руководство".

Используй сценарий "topic_research" из workflows.

Напиши подробную статью (1000+ слов) и опубликуй на Telegra.ph:
python3 /root/git/AI-journalist-bot/telegraph_publisher.py

Затем опубликуй анонс в Telegram:
python3 /root/git/AI-journalist-bot/publisher.py "текст анонса"
```

**Шаг 3: AI выполняет**

1. Исследует источники
2. Пишет статью
3. Публикует на Telegra.ph
4. Создаёт анонс
5. Публикует анонс в Telegram

**Результат:**
- ✅ Статья на Telegra.ph
- ✅ Анонс в Telegram канале со ссылкой

---

### Сценарий 3: Еженедельный дайджест

### Сценарий 4: Срочная новость


```bash
python3 /root/git/AI-journalist-bot/telegraph_publisher.py \
  "Заголовок" \
  "Содержание статьи"
```

### Публикация с анонсом

```bash
# Через Python
from telegraph_publisher import publish_with_announcement

result = publish_with_announcement(
    title="PHP 8.4: полное руководство",
    content="...",
    description="Разбираем новые фичи PHP 8.4",
    telegram_publish=True
)
```

### Обновление промтов

```bash
# Добавить правило
python3 update_prompts.py --rule "Экранировать # в тегах"

# Добавить ошибку
python3 update_prompts.py --error "Ошибка" --solution "Решение"

# Показать промты
python3 update_prompts.py --show
```

## ⚠️ Важные замечания

### Markdown V2

Всегда экранируй символы:
```
_ * [ ] ( ) ~ ` > # + - = | { } . !
```

**Пример:**
- ❌ `PHP 8.4 > PHP 8.3 #тег`
- ✅ `PHP 8\.4 \> PHP 8\.3 \#тег`

### Самообучение

AI обновляет промты после каждой сессии:
- Новые правила → `00_learned_prompts.md`
- Ошибки → `01_error_log.md`

**При запуске читай эти файлы!**

### Telegra.ph

- Не требует авторизации
- Статьи публикуются анонимно
- URL формируется из заголовка
- Редактирование возможно в течение 24 часов

## 🐛 Решение проблем

### Бот не публикует

1. Проверь токен: `cat config.json`
2. Проверь Chat ID: должен быть `-100...`
3. Проверь права бота в канале
4. Запусти тест: `python3 publisher.py test`

### Telegra.ph не публикует

1. Проверь интернет-соединение
2. Проверь формат контента (JSON)
3. Убедись, что заголовок не пустой

### AI повторяет ошибки

1. Проверь `01_error_log.md`
2. Убедись, что AI читает файл при запуске
3. Добавь правило в `00_learned_prompts.md`
