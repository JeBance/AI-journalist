# Источники данных — Оглавление

## 📚 Назначение

Эта папка содержит все источники информации для исследования новостей. AI-агент должен проверять эти источники согласно протоколу из `01_system_prompts/02_research_protocol.md`.

## 📁 Структура папки

| Файл | Описание | Количество источников |
|------|----------|----------------------|
| `01_rss_feeds.md` | RSS/Atom ленты с приоритетами | 15+ |
| `02_github_repos.md` | Репозитории для мониторинга | 20+ |
| `03_telegram_channels.md` | Telegram-каналы-источники | 10+ |
| `04_technical_blogs.md` | Технические блоги и сайты | 15+ |
| `05_newsletters.md` | Email-рассылки (архивы) | 5+ |
| `06_podcasts_and_videos.md` | Видео- и аудиоконтент | 5+ |
| `07_forums_and_communities.md` | Reddit, Stack Overflow, Dev.to | 5+ |
| `08_keywords.md` | Ключевые слова по категориям | 9 категорий |

## 🔄 Порядок проверки

1. **GitHub** (`02_github_repos.md`) — наивысший приоритет
2. **RSS** (`01_rss_feeds.md`) — высокий приоритет
3. **Telegram** (`03_telegram_channels.md`) — средний приоритет
4. **Блоги** (`04_technical_blogs.md`) — средний приоритет
5. **Остальные** — по необходимости

## 📊 Приоритеты источников

| Уровень | Тип | Когда проверять |
|---------|-----|-----------------|
| **Критический** | GitHub (Xray, php-src, node) | Ежедневно |
| **Высокий** | Официальные RSS, блоги языков | Ежедневно |
| **Средний** | Telegram, агрегаторы | 2-3 раза в неделю |
| **Низкий** | Форумы, подкасты | По необходимости |

## 📝 Формат записи источника

```markdown
### {Название}
- **URL:** {ссылка}
- **Тип:** {RSS/GitHub/Telegram/Блог}
- **Приоритет:** {критический/высокий/средний/низкий}
- **Категория:** {javascript/php/css/vpn/hardware/devops/patterns/databases/ai}
- **Описание:** {краткое описание}
```

## ✏️ Добавление нового источника

1. Открой соответствующий файл (например, `01_rss_feeds.md`)
2. Добавь запись по формату выше
3. Укажи актуальную ссылку
4. Присвой приоритет и категорию

---

**Важно:** Регулярно проверяй актуальность ссылок. Если источник перестал работать — отмечай это в файле.
