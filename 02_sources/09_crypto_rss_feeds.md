## 🔍 Как проверять

1. Открой RSS-ленту в ридере (Feedly, Inoreader)
2. Проверь новости за последние 24-48 часов
3. Для критических новостей — перепроверь в 2-3 источниках
4. Для технических новостей — сверься с официальными блогами
5. Запиши находки в кэш

## 💡 Советы по фактчекингу

### Перекрёстная проверка
- **Всегда проверяй** критические новости в 2+ источниках
- **Сравнивай** заголовки — если только один источник пишет, это может быть слух
- **Ищи первоисточник** — официальный анонс, твит проекта, GitHub

- **CoinMarketCap** — https://coinmarketcap.com/
- **CoinGecko** — https://www.coingecko.com/

## ⚠️ Предупреждения

- **Избегай** источников с пометкой "Sponsored"
- **Не доверяй** анонимным Telegram-каналам без подтверждения
- **Проверяй даты** — крипто-новости быстро устаревают
