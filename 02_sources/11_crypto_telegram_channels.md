## 🔍 Как проверять

1. Открой канал в Telegram
2. Просмотри последние 20-30 постов
3. Для security alerts — проверяй немедленно
4. Для новостей — перепроверяй в 2+ источниках
5. Сохраняй ссылки на оригинальные посты

## 💡 Советы

### Security каналы
- **Подпишись обязательно** — PeckShield, CertiK, SlowMist
- **Включи уведомления** — взломы требуют срочной публикации
- **Проверяй суммы** — разные источники могут называть разные цифры

### Новостные каналы
- **Сравнивай заголовки** — если только один канал пишет, это может быть слух
- **Ищи первоисточник** — официальный твит, блог проекта
- **Проверяй время** — крипто-новости быстро устаревают

### Предупреждения
- **Избегай** каналов с сигналами трейдинга
- **Не доверяй** анонимным инсайдерам
- **Проверяй** информацию о листингах на официальных сайтах бирж
