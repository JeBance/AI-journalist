## 🔍 Как проверять

1. Открой репозиторий
2. Перейди во вкладку **Releases**
3. Проверь релизы за последние 48 часов
4. Для критических — проверь вкладку **Issues** (security)
5. Для критических — проверь вкладку **Commits** (последние изменения)

## 📌 GitHub RSS

Для любого репозитория можно получить RSS:
```
https://github.com/{owner}/{repo}/releases.atom
https://github.com/{owner}/{repo}/commits.atom
```
