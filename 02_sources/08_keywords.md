## 📊 Использование ключевых слов

### Для поиска новостей

1. Скопируй ключевые слова категории
2. Используй в поиске по источникам
3. Отмечай совпадения как релевантные

### Для категоризации

1. Проанализируй содержание новости
2. Найди ключевые слова в тексте
3. Присвой категорию по наибольшему совпадению

### Для тегов

1. Выбери 1 основной тег (категория)
2. Выбери 2-4 дополнительных тега из ключевых слов
3. Используй в посте
