# История публикаций — Оглавление

## 📚 Назначение

Эта папка содержит **архив публикаций** для предотвращения дублирования тем и отслеживания истории канала.

## 📁 Структура папки

| Файл | Описание |
|------|----------|
| `00_index.md` | Оглавление папки |
| `01_published_posts.md` | Полный архив постов (хронологический) |
| `02_topics_covered.md` | Уникальные темы по категориям |
| `03_sources_used.md` | Статистика использования источников |
| `04_templates_used.md` | Какие шаблоны использовались |

## 🔄 Как использовать

### Перед публикацией

1. Проверь `01_published_posts.md` — не дублируется ли тема
2. Проверь `02_topics_covered.md` — не публиковалось ли это недавно
3. Если тема новая — продолжай
4. Если тема повторяется — убедись, что прошло 30+ дней

### После публикации

1. Добавь запись в `01_published_posts.md`
2. Обнови `02_topics_covered.md` (если тема новая)
3. Отметь источник в `03_sources_used.md`
4. Отметь шаблон в `04_templates_used.md`

## 📊 Формат записей

Каждая запись должна строго соблюдать формат для возможности парсинга и анализа.

## ⚠️ Важно

- **Не удаляй записи** из истории
- **Не редактируй старые записи** (только добавляй новые)
- **Проверяй актуальность** ссылок периодически
