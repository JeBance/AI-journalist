# Быстрый старт за 1 минуту

## Шаг 1: Подготовка (30 секунд)

1. Скачай эту папку на компьютер
2. Открой любой AI-агент с поддержкой загрузки файлов
3. Загрузи всю папку в AI

## Шаг 2: Первая публикация (30 секунд)

Скопируй и отправь AI эту команду:

```
Изучи все файлы в загруженной папке. Это инфраструктура IT-канала.

Затем выполни сценарий "ежедневная публикация" из папки workflows.

Telegram-канал для публикации: @[название_канала]
Chat ID: [укажи chat_id, если нужен]

После публикации запиши результат в историю.
```

## Шаг 3: Проверка

AI должен:

1. ✅ Прочитать все инструкции
2. ✅ Исследовать источники из папки `02_sources/`
3. ✅ Написать пост по шаблону из `03_templates/`
4. ✅ Показать вам черновик на утверждение
5. ✅ Опубликовать (после вашего подтверждения)
6. ✅ Записать в `06_history/01_published_posts.md`

## 🎉 Готово!

Теперь можно публиковать регулярно, просто повторяя команду.

## 🔧 Требования к AI-агенту

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| Размер контекста | 128K токенов | 200K+ токенов |
| Поддержка файлов | Да | Множественная загрузка |
| Доступ к интернету | Да | Обязательно |
| Markdown | Полная поддержка | v2 для Telegram |
