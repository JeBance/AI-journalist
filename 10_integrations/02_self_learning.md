# Самообучение AI-агента

## 📋 Назначение

Эта инструкция описывает, как AI-агент **обучается на своих ошибках** и обновляет промты.

---

```
┌─────────────────────┐
│   AI-агент запуска  │
└──────────┬──────────┘
           │
           ↓
┌─────────────────────┐
│ Чтение промтов:     │
│ - 00_main_prompt.md │

│ - 01_error_log.md   │
└──────────┬──────────┘
           │
           ↓
┌─────────────────────┐

└──────────┬──────────┘
           │
           ↓
```

## 📁 Файлы промтов

### 00_main_prompt.md

**Базовый промпт** — содержит:
- Роль и миссию
- Конфигурацию (канал, бот, Chat ID)
- Рабочий процесс
- Критические правила

**Обновляется:** Редко, при изменении конфигурации

---

### 00_learned_prompts.md

**Накопленные знания** — содержит:
- Новые правила, обнаруженные в процессе работы
- Нюансы форматирования
- Изменения в API
- Предпочтения аудитории

**Обновляется:** После каждой сессии с новыми знаниями

**Формат записи:**
```markdown
### YYYY-MM-DD: {Название правила}

**Проблема:** {описание}

**Решение:** {как решать}

**Примеры:**
- ❌ {неправильно}
- ✅ {правильно}
```

---

### 01_error_log.md

**Журнал ошибок** — содержит:
- Ошибки, которые совершал AI
- Сообщения об ошибках
- Решения
- Правила для предотвращения

**Обновляется:** После каждой ошибки

**Формат записи:**
```markdown
### YYYY-MM-DD: {Название ошибки}

**Ошибка:**
{код или действие}

**Результат:**
{сообщение об ошибке}

**Решение:**
{исправленное действие}

**Правило:** {краткая формулировка}
```

## 🔄 Процесс самообучения

### Шаг 1: Чтение при запуске

При каждом запуске AI-агент **обязан** прочитать:

1. `00_main_prompt.md` — базовые инструкции
2. `00_learned_prompts.md` — накопленные знания
3. `01_error_log.md` — известные ошибки

**Команда для AI:**
```
Прочитай файлы:
- /root/git/AI-journalist/01_system_prompts/00_main_prompt.md
- /root/git/AI-journalist/01_system_prompts/00_learned_prompts.md
- /root/git/AI-journalist/01_system_prompts/01_error_log.md
```

### Шаг 2: Выполнение задачи

AI выполняет задачу (исследование, публикация) с учётом прочитанных правил.

### Шаг 3: Обнаружение нового

Если AI обнаружил:
- **Новую ошибку** — записывает в `01_error_log.md`
- **Новый нюанс** — записывает в `00_learned_prompts.md`
- **Новое правило** — записывает в `00_learned_prompts.md`

### Шаг 4: Обновление промтов

**Вариант A: Вручную**

AI показывает команду пользователю:
```bash
python3 /root/git/AI-journalist-bot/update_prompts.py \
  --rule "Markdown V2: экранировать точку в версиях"
```

**Вариант B: Автоматически**

AI выполняет команду напрямую (если есть доступ к CLI):
```python
import subprocess
subprocess.run([
    "python3", "/root/git/AI-journalist-bot/update_prompts.py",
    "--rule", "Описание правила"
])
```

## 📝 Примеры обновления

### Пример 1: Новая ошибка форматирования

**Ситуация:** AI опубликовал пост с `#тег` без экранирования.

**Ошибка:**
```
❌ Bad Request: can't parse entities
```

**Действия AI:**

1. Распознал ошибку
2. Нашёл решение (экранировать `#`)
3. Обновил `01_error_log.md`:

```bash
python3 /root/git/AI-journalist-bot/update_prompts.py \
  --error "Markdown V2: символ #" \
  --solution "Экранировать #: \#тег"
```

4. Обновил `00_learned_prompts.md`:

```bash
python3 /root/git/AI-journalist-bot/update_prompts.py \
  --rule "Markdown V2: экранировать # в тегах"
```

---

### Пример 2: Новый источник

**Ситуация:** Пользователь добавил новый RSS-источник.

**Действия AI:**

1. Записал источник в `02_sources/01_rss_feeds.md`
2. Обновил `00_learned_prompts.md`:

```markdown
### 2026-03-25: Новый источник — Laravel News

**Проблема:** Не было источника по Laravel

**Решение:** Добавлен Laravel News

**Примеры:**
- URL: https://laravel-news.com/feed
- Категория: php
```

---

### Пример 3: Изменение в API

**Ситуация:** Telegram изменил формат Markdown.

**Действия AI:**

1. Обнаружил изменение
2. Обновил `00_learned_prompts.md`:

```markdown
### 2026-03-25: Telegram Markdown V2

**Проблема:** Старые правила экранирования не работают

**Решение:** Использовать Markdown V2

**Примеры:**
- ❌ Старый: `*жирный*`
- ✅ Новый: `*жирный*` (экранировать `_ * [ ] ( ) ~ ` > # + - = | { } . !`)
```

## 🛠️ Инструменты

### update_prompts.py

**Скрипт для обновления промтов.**

**Команды:**

```bash
# Добавить правило
python3 update_prompts.py --rule "Описание правила"

# Добавить ошибку
python3 update_prompts.py --error "Описание" --solution "Решение"

# Показать все промты
python3 update_prompts.py --show
```

**Путь:** `/root/git/AI-journalist-bot/update_prompts.py`

## 🎯 Лучшие практики

### 1. Читай перед запуском

Всегда начинай с чтения промтов. Это предотвратит повторение ошибок.

### 2. Записывай сразу

Если обнаружил новое — запиши сразу, не откладывай.

### 3. Будь конкретным

В описании правил указывай:
- Конкретную проблему
- Конкретное решение
- Примеры кода

### 4. Тестируй изменения

После обновления промтов:
- Проверь, что правило работает
- Убедись, что нет конфликтов

### 5. Не удаляй старое

Старые записи помогают понять эволюцию правил. Не удаляй их.
