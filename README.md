# IT Blog Infrastructure — AI-журналист для Telegram-канала

## 🚀 Что это?

Это файловая система знаний, которая превращает AI-агента (Claude, ChatGPT, DeepSeek, Qwen) в полноценного технического журналиста. Вам не нужен сервер, база данных или код. Только AI и эта папка.

### 🔥 Новые возможности (v1.1)

- **Публикация на Telegra.ph** — длинные статьи с анонсом в канале
- **Самообучение AI** — автоматическое обновление промтов
- **Глубокое исследование** — по запросу пользователя

## 📋 Как это работает?

1. Загружаете эту папку в AI-агента
2. Даёте команду: «Изучи папку и опубликуй свежий пост в Telegram»
3. AI исследует источники, пишет пост, публикует
4. AI записывает результат в историю

## 🎯 Быстрый старт

1. Открой `00_quick_start.md`
2. Следуй инструкции (займёт 1 минуту)
3. Готово!

## 📁 Структура

| Папка | Описание |
|-------|----------|
| `01_system_prompts/` | Инструкции для AI (роль, протоколы, чек-листы) |
| `02_sources/` | Все источники информации (RSS, GitHub, Telegram) |
| `03_templates/` | Шаблоны постов для разных форматов |
| `04_style/` | Стилистика канала, тон, правила форматирования |
| `05_categories/` | Категории контента по технологиям |
| `06_history/` | Архив публикаций (предотвращает повторы) |
| `07_research_cache/` | Временный кэш исследований |
| `08_workflows/` | Сценарии использования |
| `09_meta/` | Мета-информация проекта |

## 📝 Пример использования

```
[Загрузил папку в AI]

Выполни сценарий "ежедневная публикация" из папки workflows.
Telegram-канал: @my_it_channel
```

AI изучит инфраструктуру, исследует источники, напишет пост и опубликует его.

## 🔄 Обновление инфраструктуры

- **Добавить источник:** отредактируй соответствующий файл в `02_sources/`
- **Новый шаблон:** создай файл в `03_templates/`
- **Изменить стиль:** отредактируй файлы в `04_style/`
- **Клон для другого канала:** скопируй папку, очисти `06_history/` и `07_research_cache/`

## 📊 Ключевые преимущества

| Параметр | Классический бот | Эта инфраструктура |
|----------|------------------|---------------------|
| Код | Python/JS, тысячи строк | **Отсутствует** |
| Сервер | Нужен (VPS, Docker) | **Не нужен** |
| База данных | PostgreSQL, Redis | **Markdown-файлы** |
| Масштабирование | Инфраструктурное | **Копирование папки** |
| Сопровождение | Программист | **Редактор (текстовые правки)** |
| Запуск | Деплой, cron, systemd | **Загрузка папки в AI** |
