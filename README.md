# IT Blog Infrastructure — AI-журналист для Telegram-канала

## 🚀 Что это?

Это файловая система знаний, которая превращает AI-агента (Claude, ChatGPT, DeepSeek, Qwen) в полноценного технического журналиста. Вам не нужен сервер, база данных или код. Только AI и эта папка.

### 🔥 Новые возможности (v1.1)

- **Публикация на Telegra.ph** — длинные статьи с автоматическим форматированием
- **Анонсы в Telegram** — автоматическая публикация ссылок в канале
- **Самообучение AI** — автоматическое обновление промтов на основе опыта
- **Глубокое исследование** — по запросу пользователя

## 📋 Как это работает?

1. Загружаете эту папку в AI-агента
2. Даёте команду: «Изучи папку и опубликуй свежий пост в Telegram»
3. AI исследует источники, пишет пост, публикует
4. AI записывает результат в историю

## 🎯 Быстрый старт

### Для AI-агента

```
Изучи все файлы в загруженной папке.

Выполни сценарий "ежедневная публикация" из workflows.

Telegram-канал: @[название_канала]
```

### Для публикации статей

```bash
cd /root/git/AI-journalist-bot
python3 publish_article.py
```
