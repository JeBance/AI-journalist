# Research Cache — Оглавление

## 📚 Назначение

Эта папка содержит **временный кэш исследований** для текущей сессии AI-агента.

## 📁 Структура папки

| Файл | Описание |
|------|----------|
| `00_index.md` | Оглавление папки |
| `01_last_session.md` | Результаты последнего исследования |
| `02_processed_urls.md` | URL, которые уже обработаны |
| `03_temp_notes.md` | Заметки текущей сессии |

## 🔄 Жизненный цикл

### Начало сессии

1. Проверь `01_last_session.md` — что было найдено в прошлый раз
2. Очисти `03_temp_notes.md` — начни новую сессию
3. Начни исследование по протоколу

### Во время сессии

1. Записывай находки в `03_temp_notes.md`
2. Отмечай обработанные URL в `02_processed_urls.md`
3. Сравнивай с `01_last_session.md` для уникальности

### Конец сессии

1. Перенеси полезные находки в `01_last_session.md`
2. Очисти `03_temp_notes.md`
3. Сохрани `02_processed_urls.md` (не очищать)

## ⚠️ Важно

- **Не удаляй** `02_processed_urls.md` — это история обработанных URL
- **Очищай** `03_temp_notes.md` после каждой сессии
- **Обновляй** `01_last_session.md` только актуальным
