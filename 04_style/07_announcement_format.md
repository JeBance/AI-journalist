# Формат анонсов для Telegram

## 📋 Общие правила

### Структура поста

```
{Эмодзи} [{Заголовок}]({Ссылка})

{Краткое описание: 2-3 предложения}

{Хэштеги}
```

### Форматирование

**Заголовок:** Ссылка на статью, `[текст](url)`

**Описание:** Обычный текст

**Хэштеги:** 3-5 штук в конце

### Длина

- **Оптимально:** 150-250 символов
- **Максимум:** 1024 символа (Telegram limit)
- **Хэштеги:** 3-5 штук

## 🖼️ Изображения

### Когда добавлять

✅ **Добавлять:**
- Туториалы (скриншоты кода, интерфейса)
- Обзоры (фото устройств)
- Инфографика (схемы, диаграммы)

❌ **Не добавлять:**
- Стоковые изображения (люди за компьютером)
- Изображения без прямой связи с темой
- Картинки с текстом (дублирует пост)

### Источники изображений

**Бесплатные (без авторских прав):**

| Источник | Лицензия | Требует указания |
|----------|----------|------------------|
| Pexels | Pexels License | Нет |
| Pixabay | Pixabay License | Нет |
| Unsplash | Unsplash License | Нет |
| Wikimedia Commons | CC BY/CC0 | Зависит |

### Как прикрепить изображение

**Вариант 1: URL (если Telegram поддерживает)**

```python
requests.post(
    f'https://api.telegram.org/bot{token}/sendPhoto',
    json={
        'chat_id': channel_id,
        'photo': 'https://example.com/image.jpg',
        'caption': 'Текст поста'
    }
)
```

**Вариант 2: Загрузка файлом**

```python
with open('image.jpg', 'rb') as photo:
    requests.post(
        f'https://api.telegram.org/bot{token}/sendPhoto',
        data={'chat_id': channel_id, 'caption': 'Текст'},
        files={'photo': photo}
    )
```

## 📝 Шаблоны

### Шаблон 1: Статья

```
{эмодзи} {Заголовок статьи}

{Описание: о чём статья, 2-3 предложения}

{Призыв: Читать, Изучить, Разобраться}

{Хэштеги}
```

### Шаблон 2: Новость

```
{эмодзи} {Заголовок новости}

{Суть: что случилось, версия, дата}

{Рекомендация: обновиться, протестировать}

{Хэштеги}

{эмодзи} {Название туториала}

{Хэштеги}
```
