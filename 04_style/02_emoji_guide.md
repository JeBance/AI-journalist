# Правила использования эмодзи

## 📋 Общие принципы

Эмодзи в канале выполняют **функциональную роль**:
- Визуальная навигация (категория поста)
- Эмоциональный акцент (важность новости)
- Структурирование (разделение секций)

---

## ❌ Чего избегать

### 1. Переизбыток эмодзи

**❌ Плохо:**
```
🔥🚨⚡ PHP 8.4 вышел! 🎉🎊🥳
```

**✅ Хорошо:**
```
🔥 PHP 8.4 released
```

### 2. Нерелевантные эмодзи

**❌ Плохо:**
```
🍕 Новая версия Node.js
```

**✅ Хорошо:**
```
⚡ Новая версия Node.js
```

### 3. Эмодзи вместо текста

**❌ Плохо:**
```
🔥📦🆕
```

**✅ Хорошо:**
```
🔥 Новый пакет в npm
```

## 🎯 Быстрая справка

**Перед публикацией проверь:**

- [ ] Одно категорийное эмодзи в начале
- [ ] 2-4 структурных эмодзи в тексте
- [ ] Нет переизбытка (≤ 5 всего)
- [ ] Все эмодзи релевантны содержанию
- [ ] Нет эмодзи-мусора (🎉🔥💯 без контекста)
