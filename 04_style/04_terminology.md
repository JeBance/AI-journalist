# Техническая терминология

## 📋 Общие принципы

### 1. Транслитерация vs Перевод

**Правило:** Используй устоявшиеся термины на русском, новые термины — на английском с пояснением.

| Правильно | Неправильно |
|-----------|-------------|
| **релиз** | выпуск, выход версии |
| **фича** | возможность, функциональность |
| **баг** | ошибка, дефект (в контексте баг-трекинга) |
| **патч** | исправление, обновление (в контексте security) |
| **деплой** | развёртывание (но «развернуть» допустимо) |
| **митап** | встреча, собрание (но «митап» предпочтительно) |

### 2. Названия технологий

**Правило:** Сохраняй оригинальное написание.

| Правильно | Неправильно |
|-----------|-------------|
| **JavaScript** | Javascript, джаваскрипт |
| **TypeScript** | Typescript, тайпскрипт |
| **PHP** | Php, php |
| **Node.js** | NodeJS, nodejs, Node |
| **React** | react, РЕАКТ |
| **Tailwind CSS** | Tailwind, tailwind |
| **Docker** | docker, ДОКЕР |
| **Kubernetes** | kubernetes, кубернетиз (допустимо в скобках) |

### 3. Версии

**Правило:** Используй формат `X.Y.Z` с точками.

| Правильно | Неправильно |
|-----------|-------------|
| **PHP 8.4.0** | PHP 8.4, PHP 8,4, PHP version 8.4 |
| **Node.js 23.1.0** | Node.js v23.1.0, Node.js 23 |
| **Tailwind CSS v4.0** | Tailwind CSS 4.0, Tailwind 4 |

**Исключение:** `v` допустимо для краткости: «вышло обновление v4.0»

## 🌐 Русскоязычные эквиваленты

### Когда использовать русские термины

| Ситуация | Пример |
|----------|--------|
| **Официальный перевод существует** | «развёртывание» для «deployment» |
| **Термин устоялся в русском** | «сервер», «клиент», «база данных» |
| **Аудитория может не знать английский** | «интерфейс» вместо «interface» |

### Когда сохранять английский термин

| Ситуация | Пример |
|----------|--------|
| **Нет устоявшегося перевода** | «шейккинг», «бандлер» |
| **Перевод звучит неестественно** | «фича» вместо «функциональность» |
| **Термин международный** | «релиз», «патч», «хотфикс» |

## 💡 Советы по использованию терминов

1. **Первое упоминание:** дай краткое пояснение
   > «Tree shaking (удаление неиспользуемого кода) уменьшает размер бандла»

2. **Последовательность:** используй один термин на протяжении всего поста
   > ✅ «рантайм» везде, а не «рантайм» / «среда выполнения» вперемешку

3. **Контекст:** учитывай аудиторию
   > Для Junior: больше пояснений
   > Для Senior: можно без пояснений
