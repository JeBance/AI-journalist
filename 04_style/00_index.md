# Стиль и тон канала — Оглавление

## 📚 Назначение

Эта папка определяет **стиль, тон и правила оформления** контента в канале.

## 📁 Структура папки

| Файл | Описание |
|------|----------|
| `00_index.md` | Оглавление папки |
| `01_tone_and_voice.md` | Тон и голос канала |
| `02_emoji_guide.md` | Правила использования эмодзи |
| `03_formatting_rules.md` | Правила форматирования (Markdown V2) |
| `04_terminology.md` | Техническая терминология |
| `05_examples.md` | Примеры идеальных постов |

## 🎯 Цели стилистики

1. **Единство стиля** — все посты узнаваемы
2. **Профессионализм** — экспертный тон без снобизма
3. **Доступность** — сложное объясняется просто
4. **Читаемость** — текст легко сканировать

## 📊 Аудитория канала

| Характеристика | Описание |
|----------------|----------|
| **Кто** | Разработчики, сисадмины, DevOps, технические энтузиасты |
| **Уровень** | Middle → Senior (но понятно и Junior) |
| **Интересы** | Языки, фреймворки, инфраструктура, безопасность |
| **География** | Россия, СНГ, русскоязычные разработчики worldwide |

## ✏️ Использование

Перед написанием поста:
1. Прочитай `01_tone_and_voice.md`
2. Проверь `02_emoji_guide.md` для эмодзи
3. Используй `03_formatting_rules.md` для форматирования
4. Сверься с `04_terminology.md` для терминов
5. Посмотри `05_examples.md` для вдохновения
